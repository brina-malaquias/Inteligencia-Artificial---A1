# Inteligencia-Artificial---A1
Apresento os resultados de uma atividade prática de Redes Neurais Artificiais utilizando uma Rede Neural Multicamadas (MLP) para resolver o problema lógico XOR. Foram realizados cinco experimentos variando o número de neurônios ocultos, a taxa de aprendizagem e o número de épocas. 

**Combinação 1 (4 neurônios, 0.01, 1000 épocas):**
"A rede começou aprendendo lentamente, e o erro médio ainda estava um pouco alto ao final das 1000 épocas. Isso mostra que a taxa de aprendizagem baixa e poucas épocas resultam em um aprendizado incompleto."

**Combinação 2 (2 neurônios, 0.01, 5000 épocas):**
"Aqui tivemos uma melhora, o erro foi diminuindo gradualmente e a rede conseguiu aprender o padrão. Porém, com apenas 2 neurônios, o aprendizado é mais limitado, mesmo com mais épocas."

**Combinação 3 (4 neurônios, 0.01, 10000 épocas):**
"Esse foi um dos melhores resultados. A rede aprendeu de forma estável, e o erro caiu bem mais. O número de épocas maior compensou a taxa de aprendizagem baixa."

**Combinação 4 (6 neurônios, 0.5, 5000 épocas):**
"Aqui vimos instabilidade no gráfico. A taxa de aprendizagem muito alta fez com que o erro ficasse oscilando, o que mostra que a rede teve dificuldades para convergir corretamente."

**Combinação 5 (6 neurônios, 0.1, 10000 épocas):**
"Com essa configuração, a rede teve um desempenho bom. A taxa de 0.1 permitiu um aprendizado mais rápido e estável, e o número maior de épocas ajudou a chegar a um erro bem pequeno."
